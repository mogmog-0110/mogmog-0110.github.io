3D 煙＆炎のリアルタイム GPU シミュレーション

3D グリッド上で流体方程式 (Navier-Stokes) を GPU で解き、できた密度・温度場をボリュームレイマーチで立体的に描く、煙と炎のリアルタイムデモです。

流体ソルバ・炎の発光・ボリューム描画・自己影・インタラクティブ UI までを一式、自作エンジンの DX12 コンピュート基盤の上にフルスクラッチで実装しました。手法そのものは映画・ゲームで長く使われてきた古典 (後述) ですが、論文を読んで自分の手で動くところまで通したのが主眼です。

ExperimentC++20 / HLSLDirectX 12 ComputeMitiruEngine2026

作ったもの

128³ のボクセルグリッドを毎フレーム GPU で更新し、立ち上る炎と煙をリアルタイムに描画します。 ウィンドウ内のスライダーで浮力・冷却・乱流・発光・色などをその場で変えられ、 複数のプリセットを横に並べて同時に見比べることもできます。

手法

1 フレームで以下を順に GPU コンピュートシェーダで解きます。全フィールド (速度・密度・温度・圧力) は 3D テクスチャに置き、CPU へ戻さず GPU 上で完結させています。

① グリッド流体シミュレーション (Stable Fluids)

速度場を「移流 → 外力 → 圧力射影」で更新します。移流は semi-Lagrangian (速度を逆向きに辿って値を拾う) で無条件に安定。 非圧縮 (= 体積保存) を満たすために、速度の発散を計算し、ポアソン方程式を Jacobi 法 40 反復で解いて圧力を求め、その勾配を引いて発散ゼロの流れに直します。煙・温度もこの速度場で一緒に流します。

② 渦 confinement (乱流ディテールの復元)

グリッド法は数値拡散で細かい渦が潰れ、放っておくと「のっぺりした層流の一本柱」になりがちです。 そこで速度場の回転 (渦度) を計算し、その大きさが増す方向へ小さな力を足し戻して、消えかけた渦を強調します。 これで炎が舌のように巻き、煙がもくもくと崩れる乱流のディテールが戻ります。

③ 炎の色 = 黒体放射

炎の色は温度で決まります。火源に与えた熱が上昇とともに冷えていく過程を、温度 → 色 (暗赤 → 赤 → 橙 → 黄 → 白) のグラデーションに写像して発光させています。 温度のスケールと色テーブルを差し替えるだけで、橙の焚き火から青いガス炎まで作り分けられます。

④ ボリュームレイマーチ + 自己影

描画はカメラから光線を飛ばし、グリッドを小刻みにサンプリングしながら色を積算します。 煙は密度に応じて光を吸収 (Beer–Lambert)、炎は温度の発光を加算。 さらに各サンプル点から光源方向へ二段目の短い光線を飛ばして「そこへ届く光の量」を測り、 煙の自己影を付けることで、平面的でない立体感を出しています。

デモ（横並び比較・ライブ調整）

それぞれ独立にシミュレートした複数のシムを横に並べ、同時に走らせて見比べられます。 ウィンドウ内で並べる数 (1〜4) と各タイルのプリセットを切り替えられ、コマンドの打ち直しは不要です。

この技術の立ち位置

正直に書くと、ここで使った手法はどれも最先端の研究ではなく、確立された古典です。 グリッド流体は Stam の Stable Fluids (1999)、煙と渦 confinement は Fedkiw ら (2001)、炎は Nguyen ら (2002)、 GPU での実時間 3D 化は GPU Gems 3 (2007) が原典で、映画やゲームの煙・炎の土台になっています。

このデモの価値は新規性ではなく、その古典パイプラインを論文から起こして、自作の DX12 エンジンの上で動くところまで一通り実装したこと ── コンピュートシェーダ、3D テクスチャの取り回し、ボリューム描画、リアルタイムの調整 UI を自分で組んだ点にあります。
