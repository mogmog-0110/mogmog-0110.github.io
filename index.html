ABOUT

会津大学大学院 修士1年。C++ とグラフィックス API を軸に、ゲーム・ゲームエンジン・物理シミュレーションを横断して開発しています。現在は CG をメインに、個人でも研究・開発を進めています。

2026年1月から株式会社 Live2D で Cubism SDK for Native（C++）まわりのアルバイトをしており、SDK の保守・不具合対応に携わっています。学部ではゲーム制作サークルの部長として、企画からシナリオ・イラスト・実装まで担当しながらチームでゲームを作ってきました。
