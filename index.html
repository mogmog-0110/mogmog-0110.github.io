About Me

川村優弥 / Shiggy。ゲームを作っています。
学部時代にチームを率いてゲームを作り、シナリオも絵も自分で書いてきました。

現在は会津大学大学院（M1）。株式会社 Live2D で Cubism SDK for Native（C++）の保守・不具合対応のアルバイトに従事していて、グラフィック API まわりのプロダクションコードに日常的に触れています。

並行して、剛体物理シミュレーションで化学現象を再現する研究をしていて、国際会議 BDA 2025（Springer LNCS）に第一著者で論文を出しました。
必要な道具がないときは自分で作ります。Siv3D 向けの GUI ツール、自作レンダラー、C++ で書いている自作ゲームエンジン（開発中）など。
