ハトを育てよう

ゲームの作り方を教えるために制作したノベルゲームです。 ハトへの行動を選ぶことで、その状態と結末が変化します。 後に自作の MitiruEngine で再現しました。

2023年 個人開発 MitiruEngine CEF + JavaScript mitiru.novel

作品について

企画開発部には、シナリオ制作を学ぶ「シナリオ部」という活動があり、私は教える側として参加していました。ティラノスクリプトを使ったゲーム制作を教える際、実際に動くサンプルとして本作を制作しました。そのための教材です。

プレイヤーはハトに対する五種類の行動を選び、その状態に応じた結末を迎えます。結末は五つです。後に自作のMitiruEngineで再現し、バックログや既読スキップ、セーブとロードを備えました。

時間をかけずに作った作品でしたが、学祭やOBから好評を得ました。蒼翔祭2023では、子供たちが実際に遊び、楽しそうにしている姿を見ることができました。作ってよかったと感じました。

ゲーム画面

MitiruEngineで作り直した理由

ティラノスクリプト版はゲームとして完成していましたが、エンジンを自分で書いたわけではないので、改造や流用が利きませんでした。そこで自作のMitiruEngine上へ移し、エンジン同梱のノベル機能mitiru.novelを初めて実作品で使いました。

仕様を隅まで把握しているゲームを選んだのは、自作エンジンが実際の制作に使えるかを確かめるためです。

ゲームの中身

  • 1280×720の画面と座標
  • day、stress、yaruki、tinou、kinniku、taijuu、val、scoreの各パラメータ
  • 「あそぶ」「勉強」「ごはん」「筋トレ」「叱る」の5種類の行動
  • stress、yaruki、taijuuに応じた立ち絵の切り替え
  • 「逃亡」「死亡」「ふくろう」「ムキムキ」「ふつう」の5エンディング
  • スコア計算
  • music.oggのループ再生

スコア計算式: tinou*1000 + kinniku*1000 − stress*100 + yaruki*100 (+2000 end3/end4)

MitiruEngine版で足した機能

  • バックログ（履歴ボタン／Lキー）
  • 既読管理と既読スキップ
  • セーブ・ロード（novel.save(slot)／novel.restore(slot)）
  • 毎秒40文字のタイプライター演出
  • 400msの背景クロスフェード

仕組み

MitiruEngineのHybrid動作（CEF + JavaScript）を使用しています。 シナリオはJSONファイルとしてゲーム本体から分離し、 JSON駆動のノベル機能mitiru.novelが解釈します。 同じデータをブラウザとCEFネイティブの両方で動かせます。 

ティラノスクリプト .ks   →  MitiruEngine 側の対応
─────────────────────────────────────────────────
#キャラ名 + テキスト       →  { speaker, text }
@bg storage=...            →  { type: 'bg', path }
[wait time=N]              →  { type: 'wait', ms }
[delay speed=10]           →  mitiru.novel 組込（CPS 40）
[button role="skip"]       →  novel.setSkipMode('all')

stress、yaruki、taijuuの値で内容が分岐する行動シーンでは、 実行時にJSONを動的に生成します。

位置づけ

MitiruEngineで初めて完成形まで制作したゲームです。 エンジン単体の動作だけでなく、プレイ可能なゲーム全体を載せられる段階に達したことを示しています。
