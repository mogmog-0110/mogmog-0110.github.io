ハトを育てよう

MitiruEngine リメイク

2023年にTyranoScriptで制作したゲームを、自作の MitiruEngine へ完全移植し、新しい機能を加えた作品です。

リメイク作品 MitiruEngine CEF + JavaScript mitiru.novel

作品概要

原作は、2023年に2日で制作したノベルゲームです。 5種類の行動を選びながらハトを育て、状態に応じて5つのエンディングへ分岐します。

リメイクでは原作のゲーム内容を再現しながら、バックログ、既読スキップ、セーブ・ロードなどを追加しました。 自作エンジンで、ひとつのゲームを完成形まで動かせることを確かめた作品でもあります。

ゲーム画面

リメイクの目的

原作はゲームとして完成していましたが、エンジン自体を自分で書いたものではなく、改造や流用が利きませんでした。 そこで、原作を自作のMitiruEngine上に移し、エンジン同梱のノベル機能 mitiru.novelを初めて実作品で使用しました。

仕様を把握しているゲームを再現することで、自作エンジンが実際の制作に使えるかを検証しました。

再現した内容

  • 原作に準拠した1280×720の画面と座標
  • day、stress、yaruki、tinou、kinniku、taijuu、val、scoreの各パラメータ
  • 「あそぶ」「勉強」「ごはん」「筋トレ」「叱る」の5種類の行動
  • stress、yaruki、taijuuに応じた立ち絵の切り替え
  • 「逃亡」「死亡」「ふくろう」「ムキムキ」「ふつう」の5エンディング
  • 原作のスコア計算
  • music.oggのループ再生

スコア計算式: tinou*1000 + kinniku*1000 − stress*100 + yaruki*100 (+2000 end3/end4)

リメイクで追加した機能

  • バックログ（履歴ボタン／Lキー）
  • 既読管理と既読スキップ
  • セーブ・ロード（novel.save(slot)／novel.restore(slot)）
  • 毎秒40文字のタイプライター演出
  • 400msの背景クロスフェード

仕組み

MitiruEngineのHybrid動作（CEF + JavaScript）を使用しています。 シナリオはJSONファイルとしてゲーム本体から分離し、 JSON駆動のノベル機能mitiru.novelが解釈します。 同じデータをブラウザとCEFネイティブの両方で動かせます。 

原作 .ks の機能           →  MitiruEngine 側の対応
─────────────────────────────────────────────────
#キャラ名 + テキスト       →  { speaker, text }
@bg storage=...            →  { type: 'bg', path }
[wait time=N]              →  { type: 'wait', ms }
[delay speed=10]           →  mitiru.novel 組込（CPS 40）
[button role="skip"]       →  novel.setSkipMode('all')

stress、yaruki、taijuuの値で内容が分岐する行動シーンでは、 実行時にJSONを動的に生成します。

位置づけ

MitiruEngineで初めて完成形まで制作したゲームです。 エンジン単体の動作だけでなく、プレイ可能なゲーム全体を載せられる段階に達したことを示しています。

原作『ハトを育てよう』: shiggy／TyranoScript Ver5.20
