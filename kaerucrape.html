かえるくれーぷ（Kaeru Crepe）

クレープ店の運営とヒロインとの交流を描く、美少女ゲーム × クッキングゲームです。注文に合わせてクレープやドリンクを作る調理パートと、会話を進めるノベルパートで構成しています。

Godotで制作した体験版をコミックマーケット106で無料配布した後、自作のMitiruEngineへ移植しました。MitiruEngine版では、ゲーム画面とUIをHTML/CSSで実装しています。

開発中 MitiruEngine HTML / CSS C++ 2人チーム
体験版（Godot版）をダウンロード →

MitiruEngine版

タイトル、調理、ノベル、シフト結果までの画面です。各画像はクリックすると拡大できます。

ゲーム概要

傾いたクレープ店を、ヒロインたちと一緒に立て直していくゲームです。注文をリアルタイムで処理するクッキングシフトと、朝や夜のノベルを行き来しながら日々を進めます。

クッキングパート

マウスまたはタッチで食材を動かし、注文に合うクレープを作ります。フルーツ、ソース、ホイップ、トッピング、アイスを組み合わせ、完成した商品を提供します。

注文には待ち時間があり、完成内容や提供までの時間が評価に影響します。注文票では必要な具材を確認できます。クレープのほか、フルーツジュースやコーヒーを含む複数品の注文もあります。

ノベルパート

調理の前後にヒロインとの会話を進めます。現在のMitiruEngine版では、タイトルから朝のノベル、調理、シフト結果、翌日へ進む流れが動作しています。

メインメニューと本編シナリオは制作中です。

HTML / CSSで作るゲーム画面

MitiruEngineはCEF（Chromium Embedded Framework）を画面合成に利用できます。本作では、HUD、注文票、食材棚、プレート、結果表示などをHTML/CSSで組みました。

ゲームの状態とルールはC++側で管理し、宣言的バインダのdata-m-* 属性を通してDOMに反映します。ゲーム固有のJavaScriptは、ドラッグ操作を接続する1箇所だけです。

HTMLからC++へはドラッグの着地やボタン操作をシグナルとして送り、C++からHTMLへは状態を渡します。画面表現とゲームロジックを分けて管理する構成です。

実装した主な機能

  • DLL単位のゲームコードとホットリロード
  • 食材のドラッグ＆ドロップとレシピ判定
  • 注文の待ち時間、売上、チップ、コンボ
  • 焼き工程、フルーツのカット、トッピングの合成、商品の提供
  • ジューサーとエスプレッソのドリンクステーション
  • クレープとドリンクを組み合わせた複数品注文
  • 注文票の具材チェックリスト
  • クレープの食材レイヤー合成
  • 期限付きの総売上目標とヒロイン好感度
  • タイトル、朝のノベル、調理、結果の日次ループ
  • 各調理ステーションのアップグレード機構

データと開発基盤

デザインシステム

配色、文字、余白、角丸、影の値を、DESIGN.mdのYAMLフロントマターにまとめています。

レシピと食材

レシピは必要食材、価格、難易度、注文するヒロインを持つテーブルとして定義しています。食材は1種類を1 bitで表し、注文とプレートの状態をビットマスクで比較します。

ゲーム状態

ゲーム状態を、ポインタや可変長データを持たないflatなPODにまとめています。セーブ、巻き戻し、自動リプレイへ利用できる構成です。

アセット管理

アセットのキーとURLをマニフェストで分離し、コードを変更せずに差し替えられるようにしています。

Godot版からの移植

最初のバージョンはGodotで制作し、コミックマーケット106で体験版を配布しました。その後、調理シーンとレシピ・食材データをMitiruEngineの構成へ作り直しました。

MitiruEngine版では、DLLのゲームコード、HTML/CSSのUI、ホットリロードを使い、調理パートをプレイできる状態まで実装しています。

コミックマーケット106で配布したGodot版の画面です。

現在の状況

MitiruEngine版の調理パートと日次ループは動作しており、メインメニュー、本編シナリオ、最終アートを順に追加しています。完成版は学園祭での展示を予定しています。
