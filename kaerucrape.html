なぜこのゲームか

学生のうちに美少女ゲームを一本仕上げたい、というのが個人的な目標でした。シナリオもシステムも、自分が「面白い」と思えるところまで一人で詰めるための作品です。

題材は「落ちぶれた店の再建」。日常を回しながら関係を深めて店を立て直していく、という構造で、ノベルゲームと経営シミュレーションをキャラクターを軸に繋げたかったのが出発点です。

なぜ Godot を選んだか

過去作で慣れていた Siv3D や Unity を使う選択肢もありましたが、今作では Godot にしました。理由は次のとおりです。

  • Windows / macOS / Linux / Web まで 1 プロジェクトで書き出せること。完成版を広く届けるために大きい。
  • MIT 寄りのライセンスで、商用利用に追加コストがかからないこと。
  • Unity のコンポーネントとも Siv3D のクラス設計とも違う、Godot のノード構造を実装する側から理解したかったこと。
  • GDScript の書き味。C++ ほど堅くなく、書き捨ても効くがクラスも組める塩梅が、シナリオ進行のコードと相性が良いこと。
