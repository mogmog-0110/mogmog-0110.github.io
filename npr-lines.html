NPR 輪郭線の時間安定化

3D モデルから生成したトゥーン輪郭線のちらつきを抑える実験です。

TAA で使われる、motion vector によって前フレームを再投影し、現在のフレームと合成する方法を輪郭線へ応用しました。必要な描画処理、比較デモ、定量計測を自作ゲームエンジン MitiruEngineに実装しています。

Experiment C++20 MitiruEngine NPR / トゥーン 2026

成果

前フレームの情報を利用して輪郭線を安定させ、フレーム間のちらつきを 63%、線幅の変動を 67% 減らしました。数値は自動テストで計測しています。

実装

  • G-buffer への motion vector と objectId の追加
  • 前フレームを保持する double-buffer
  • 深度の差と法線の折れを使う screen-space 輪郭抽出
  • 再投影と履歴検証による時間安定化
  • EMA 方式と、線の中心を保つ dropout-filling 方式
  • 両方式の CPU 版と GPU 版
  • 変形メッシュの頂点単位の速度計算
  • glTF / VRM 読み込み
  • 線幅などを調整する後処理

VRM モデルでの比較

ニコニ立体ちゃん（©dwango）を VRM から読み込み、背面法のアウトラインと screen-space の内側線を組み合わせました。ピッチとヨーを変えた複数の視点を事前にレンダリングし、ドラッグによる回転とズームができるブラウザ用ビューアも制作しました。

リアルタイム布デモ

Verlet 法による質点ばねモデルの布へランダムな突風を当て、変形によって現れる線を描画します。MitiruEngine の Game DLL として実装し、安定化前後の輪郭線を並べました。
