オスカーのガーデニング

オリジナルキャラクターのオスカーを、魅力的に知ってもらうために作った作品です。

2026年 2人制作 MitiruEngine C++20 DirectX 12 HTML / CSS HUD

この作品について

2026 年 8 月 23 日、東京ビッグサイトで一次創作オンリーの同人イベント COMITIA157 が開かれました。本作は、そこで頒布した作品のひとつです。

ゲーム開発部というサークルの後輩と、2 人で制作しました。オスカーは後輩のオリジナルキャラクターです。制作にあたり、キャラクター素材の提供を受けました。実装はすべて川村優弥が担当しています。

オスカーを知る入口として遊んでもらい、その歌声や振る舞い、プレイヤーとのやりとりまで好きになってもらうことを目指しました。

仕組み

ゲーム本体は C++ で実装しています。庭やキャラクター、苗、じょうろ、演出などの描画とゲーム進行を担います。

会話、音量パネル、立て札、結果表示は HTML と CSS で書きました。CEF の透過ウェブビューとして、ゲーム画面の上に重ねています。C++ 側は文字を一切描きません。

デスクトップ版では CEF を利用します。ブラウザ版では同じ表示をウェブページ上へ配置し、ゲーム本体を Emscripten と WebGL で動かしています。

庭を構成する 3DCG

庭の背景は 3D で組んでいます。芝、柵、柵際の草には glTF 形式のモデルを使い、拡張子は .glb です。

柵の横木と柱、レンガの擁壁は、立方体を 1 個ずつ並べて形を作りました。花壇の土は平面です。そこへテクスチャを貼っています。

3D の景色には、トゥーン調の陰影と輪郭線をかけました。苗、じょうろ、雲は 2D スプライトです。足元には楕円の影を敷き、地面に接して見えるようにしています。

こだわったこと

オスカーを伝える音

オスカーの魅力を伝えるため、歌、声、効果音を大切にしました。説明や反応を声で聞かせ、ゲーム中の行動にもそれぞれ音を付けています。

種まきと水やりには別々の音があります。長押し中はひとつの音を継続して鳴らし、水の広がりを感じられるようにしました。空振りには小さな水音だけを返します。

キャラクターとのやりとり

オスカーが種をまき、次の小節でプレイヤーが水をやります。この呼びかけと応答の形そのものが、オスカーとのやりとりです。

種をまいた位置と、水をやる拍は対応しています。オスカーの歌と動きを受け取り、自分の操作で応える流れにしました。短いゲームです。その中で、一緒に庭を育てた感覚が残るように設計しています。

朝から日暮れへ移る色

本編が進むにつれて、空の色は朝から日暮れへ変わります。その光の色は、3D の陰影にも 2D のスプライトにも同じように掛かります。

終盤へ近づくほど、庭全体が夕方の色に包まれます。遊びの進行と景色の変化を重ね、ひと続きの時間として感じられる雰囲気を作りました。

ブラウザで遊ぶ

ダウンロードやインストールは不要です。約 6 MB の読み込み後、ブラウザで遊べます。音が出ます。

Windows 版は 配布ページ にあります。
