Makina

球や円柱を足したり削ったりして立体を作る、開発中のモデラーです。 テクスチャを貼る代わりに、角の摩耗や窪みの汚れを形そのものから計算します。 形を変えると、汚れや摩耗も追従します。

開発中 2026年 個人開発 C++20 DirectX 12 SDF レイマーチ

できること

立体の作成、アニメーション、形に応じた質感表現

左のツリー、中央のビューポート、右のプロパティ、下のタイムラインを備えています。 UI は HTML と CSS で描画しています。

3 枚とも実機でのレンダリング結果です。ペットボトルとペンローズの三角形は、Grasp3D の課題を移植したものです。

開発の経緯

Java 製の教育ツールを修正し、C++ へ移植

大学の授業で、Java 製の教育用 3DCG モデラー「Grasp3D」を使用しました。 球や円柱を組み合わせて形を作り、POV-Ray に渡して描画するツールです。 はじめに原典のバグを修正し、機能を追加した版を作りました。

その後、同じ仕組みを C++ で書き直しました。 Java 版のように形をポリゴンへ変換せず、距離場のまま GPU でレイマーチする構成です。 この移植から Makina が生まれました。

正しさの検証

同じ形を、独立した 3 通りの方法で比較

移植が正しいことを確かめるため、距離場、BSP、POV-Ray という壊れ方の異なる実装を突き合わせています。

  • 距離場と Java 参照実装：51,137 サンプルが一致
  • 距離場と BSP の内外判定：156,932 サンプルが一致
  • 距離場と POV-Ray の画像：シルエットの一致度が 0.9949 以上

シルエットの比較では、形、変換、カメラ、座標系の向きをまとめて検査できます。 座標系の向きが異なる場合、一致度はほぼ 0 になります。

汚れと摩耗の計算

画像を貼らず、形を評価して求める

Makina は距離場を使い、次の表現をその場で計算します。

  • 角の尖り具合と外からの見え方で決まる、縁の摩耗
  • 窪みと光の届きにくさで決まる、溜まった汚れ
  • 上の開き方と面の傾きで決まる、流れ落ちる汚れ
  • 面の向きと摩耗の有無で決まる、積もった埃

溝の半径を変えると、汚れの位置も一緒に変わります。 溝とボルト穴が交わる場合は、その交点にも汚れが溜まります。

自作エンジンとの連携

Makina で作った形は、自作ゲームエンジンへ渡せます。 距離場を描画と衝突判定の両方に使うため、それぞれに別の形状データを用意する必要はありません。

形を評価する makina-core は、GPU やエンジンに依存しないヘッダーのみのライブラリです。 ウィンドウやグラフィックスデバイスを用意せずにテストできます。
